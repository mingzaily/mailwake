# 管理界面

[English](console.md) · [文档目录](README.zh-CN.md)

管理界面使用 React、TypeScript、shadcn/ui、Tailwind v4 与 hash 路由。侧栏将邮箱列表和添加入口归入“邮箱”导航，并显示连接额度。进入邮箱后默认展示独立的“监听状态”页面，“邮箱设置”单独维护连接信息，“扫描文件夹”弹窗分为扫描、选择和确认保存三步，固定高度，长列表在内部滚动，标题和操作按钮保持可见。页面包括概览、邮箱连接与文件夹检查、通知设置、最近 50 条投递、运行日志、管理员设置、API Token 和脱敏诊断。删除邮箱和撤销 Token 使用行内确认。

中英文共用后端文案目录，首次按 Accept-Language 选择语言；设置页可切换语言和主题。主题默认跟随系统，支持显式深色与浅色。360px 起提供窄屏抽屉和键盘操作。概览每 5 秒刷新，隐藏页面时暂停；日志每 3 秒增量刷新，可筛选、暂停和导出，上翻时暂停自动跟随。日志导出包含文件夹名称。

鉴权使用 HttpOnly Cookie 会话；CSRF 和新建 API Token 只保存在内存，本地存储仅保存语言与主题。凭据只写不读；校验和网络错误保留输入，revision 冲突提供重新加载，限流显示等待秒数。脚本可使用 `Authorization: Bearer mwk_…`。

二进制内嵌带哈希的脚本、样式与 Geist 字体。首页及文案使用 no-store，`/assets/*` 使用一年 immutable 缓存。CSP 仅允许本站脚本、样式、字体和连接，以及 data 图片；界面无内联脚本、style 标签或 style 属性。字体 OFL 和其他第三方许可随产物提供，可访问 `/third-party-notices.txt`。
