# 管理界面

[English](console.md) · [文档目录](README.zh-CN.md)

初始化先展示欢迎介绍，点击“继续”后开始设置。设置包含三步：创建管理员、添加邮箱、选择文件夹。开场介绍与三步共用页面宽度和进度栏，步骤计数从创建管理员的第 1/3 步开始。开场内容短暂淡入，并遵循系统减少动态效果的偏好。添加邮箱时先测试连接，成功后启用保存；修改连接字段后需重新测试。测试发现的文件夹直接带入第三步展示和选择。完成或跳过后进入通知设置。“App 设置”位于“通知设置”上方，负责手机连接和管理授权；通知渠道独立配置，支持 App 管理与 Bark 推送组合使用。

管理界面使用 React、TypeScript、shadcn/ui、Tailwind v4 与 hash 路由。侧栏将邮箱列表和添加入口归入“邮箱”导航，底部提供 GitHub 链接和管理员账户菜单。顶部显示面包屑与监控汇总，桌面侧栏支持展开和收起。连接额度在邮箱页面与文件夹选择中显示。进入邮箱后默认展示独立的“监听状态”页面，“邮箱设置”单独维护连接信息，“扫描文件夹”弹窗分为扫描、选择和确认保存三步，固定高度，长列表在内部滚动，标题和操作按钮保持可见。页面包括概览、邮箱连接与文件夹检查、通知设置、最近 50 条投递、运行日志、管理员设置、API Token 和脱敏诊断。删除邮箱和撤销 Token 使用行内确认。

界面共用后端的九种语言文案目录，首次按 Accept-Language 选择语言；设置页可切换语言和主题。主题默认跟随系统，支持显式深色与浅色。360px 起提供窄屏抽屉和键盘操作。概览每 5 秒刷新，隐藏页面时暂停；日志每 3 秒增量刷新，可筛选、暂停和导出，上翻时暂停自动跟随。日志导出包含文件夹名称。

鉴权使用 HttpOnly Cookie 会话；CSRF 和新建 API Token 只保存在内存，本地存储仅保存语言与主题。凭据只写不读；校验和网络错误保留输入，revision 冲突提供重新加载，限流显示等待秒数。脚本可使用 `Authorization: Bearer mwk_…`。

二进制内嵌带哈希的脚本、样式与 Geist 字体。首页及文案使用 no-store，`/assets/*` 使用一年 immutable 缓存。CSP 允许本站脚本、样式、字体和连接，以及 data 图片。每次首页响应生成独立的样式 nonce，前端通过 get-nonce 授权 Radix 滚动锁样式；构建时计算 Sonner 固定样式的 SHA-256，随产物授权。脚本限制保持不变，策略保持无 unsafe-inline、unsafe-eval。字体 OFL 和其他第三方许可随产物提供，可访问 `/third-party-notices.txt`。

文件夹扫描优先根据 IMAP 标准用途显示本地化名称，缺少用途时按常见名称精确匹配；翻译后附带原名，自定义路径和订阅保留原始值。发现的文件夹默认展开。选择 App 推送后，测试通知等待已连接的推送设备，并提供 App 设置入口。设置表单限宽居中；日志显示本地化摘要，原始属性收在技术详情中。诊断页直接显示软件版本、构建提交与运行平台，未提供的提交号明确标注。

侧栏底部显示当前管理员用户名和账户菜单。界面偏好使用与登录页一致的图标加文字小菜单，分别选择语言和主题。首次配置通知采用当前网站语言，已保存的通知语言独立保留。

IMAP 快捷填写直接展示 QQ、163、126、iCloud 和 Gmail；“更多邮箱”按个人邮箱（Yeah、雅虎、阿里个人邮箱）与企业邮箱（腾讯企业邮箱、阿里企业邮箱）分组。快捷项只填写服务器地址与 TLS 端口 993。已配置凭据的留空提示放在输入框占位文字中。

## 手动清除记录

投递记录的「清除记录」永久删除全部已结束记录，包括可手动重试的失败记录，范围覆盖最近 50 条之外的历史。待投递、自动重试、仍在进行的 Native 状态检查与待处理活动更新会保留；邮箱检查点和配置保持原样。

运行日志的「清除日志」清除 Core 内存中所有级别、所有邮箱的日志；容器标准错误日志和已导出文件保留，新日志继续写入。日志序号保持递增，轮询客户端通过 `cleared_through` 丢弃已清除内容。两个操作均需要确认和管理员鉴权，浏览器请求校验 CSRF。

### 表单操作与结果提示

表单底部操作区在所属卡片内右对齐，保存、完成等主操作位于最右侧，测试等次要操作排在前面。输入框旁的快捷操作、表格行操作保持靠近对应内容。窄屏时按钮自然换行。

操作成功与短暂失败统一使用右上角提示，成功停留 4 秒、失败停留 8 秒，可手动关闭；多条提示由 Sonner 堆叠展示。字段校验保留在输入框旁，配置冲突在表单内保留重新加载入口。加载失败和持续断线使用页面常驻提示。原生弹窗的失败原因留在弹窗内，确保在浏览器顶层可见。

短暂操作结果统一使用 Sonner：右上角显示，成功为绿色、失败为红色，分别停留 4 秒和 8 秒，桌面默认宽度为 300px，移动端沿用 Sonner 的适配。成功文案简述结果，失败提示保留原因与处理建议。关闭按钮位于右侧内部，底部细线贴齐边缘展示剩余时间；悬停、按住和切换到后台时暂停，减少动态效果模式隐藏细线。提示跟随主题。字段校验和持续异常使用行内提示。组件依赖升级后验证正式构建中的 CSP 与键盘行为。
